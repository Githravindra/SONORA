# SONORA Premium Music App Backend

A production-oriented FastAPI backend for the SONORA music streaming platform.

## Overview

This backend provides a modular API for the SONORA frontend, including:
- authentication and user access
- music catalog browsing
- playlist management
- library and likes
- playback tracking and history
- recommendation discovery
- global search
- analytics and settings

## Quick start

1. Create a virtual environment
2. Install dependencies: `pip install -r requirements.txt`
3. Copy `.env.example` to `.env` and update values
4. Run the app: `uvicorn app.main:app --reload`

## Notes

This repository contains backend code only.
